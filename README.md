# SahayakAI: Multimodal Community & Problem Solver

## Overview
SahayakAI is an AI-powered multi-modal assistant designed to help everyday people solve local community issues, analyze documents, and brainstorm instant solutions using Google's Gemini API.

## How AI is Used
- **Text Processing:** Generates structured solutions for complex text queries and local prompts.
- **Vision/Multimodal Processing:** Analyzes uploaded images, screenshots, or documents to extract insights and provide instant recommendations.

## Tech Stack
- Python & Streamlit (Cloud Frontend & Backend)
- Google GenAI SDK (`gemini-1.5-flash`)

## How to Run
1. Enter your Gemini API Key in the sidebar.
2. Type a problem statement or upload an image.
3. Click generate to view instant AI results!
