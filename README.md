# 🤖 Sahayak-AI1 - Multilingual AI Assistant

**Sahayak-AI1** is a high-accessibility and fast multilingual AI assistant powered by Google Gemini AI.

---

## 🎯 Background & Purpose: Why Was This WebApp Built?

In rural and non-technical areas across India, many users face significant challenges when interacting with modern technology and digital tools. The primary barriers include:
* **Language Barriers:** Most advanced AI tools are exclusively in English, making them inaccessible to local and regional populations.
* **Accessibility Issues:** Small fonts and complex user interfaces make it difficult for everyday users to read and navigate comfortably.
* **The Solution:** **Sahayak-AI1** was created to bridge this digital divide. It empowers users to communicate in their native languages (Hindi, Punjabi, or English) to solve local problems—such as crop diseases, government scheme information, and energy-saving tips—using text, voice, or images to get instant, professional solutions.

---

## 🌟 Key Features

* **🌐 Multilingual Support:** Seamlessly switch between English, Hindi (हिंदी), and Punjabi (ਪੰਜਾਬੀ).
* **🔤 Accessibility Controls:** Real-time font size adjustment controls (`A-`, `14px`, `A+`) for enhanced readability.
* **⚡ High-Contrast Dark Theme:** Sleek dark-gradient UI with pure white typography for optimal visibility.
* **🔑 Secure API Key Management:** Robust session-state handling that retains user credentials across language switches.
* **💬 Text Solver:** Interactive problem-solving interface with one-click quick suggestion chips.
* **🎙️ Voice & Audio Assistant:** Upload audio recordings (`WAV`, `MP3`) for direct AI audio analysis.
* **🖼️ Image Analyzer:** Upload images or documents for visual explanation and insights via Gemini Vision capabilities.

---

## 🚀 Step-by-Step Guide: How to Use the App

Follow these simple steps to use Sahayak-AI1 effectively:

1. **Open the Application:** Access the deployed Streamlit app via your web browser.
2. **Select Language:** Use the sidebar dropdown menu to choose your preferred language (English, Hindi, or Punjabi).
3. **Enter API Key:** Input your Google Gemini API Key in the sidebar's password field. A green connected status indicator will appear upon successful validation.
4. **Choose a Feature Tab:**
   * **Text Solver:** Type your question or click on any of the quick suggestion chips.
   * **Voice Helper:** Upload an audio file and click the analysis button.
   * **Image Analyzer:** Upload an image/photo and provide custom instructions for AI analysis.
